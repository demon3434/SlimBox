======================================================================
       SlimBox 局域网硬件加速视频压制微服务 (Windows 独立绿色版)
======================================================================

【快速启动】
  直接双击运行 [slimbox.exe] 即可：
  1. 软件启动后无任何黑色命令行窗口，右下角系统托盘区域会自动出现 SlimBox 图标。
  2. 系统将自动唤起默认浏览器打开 Web 管理界面 (http://localhost:8080)。
  3. 局域网内其他设备 (手机、平板、其他电脑) 亦可直接在浏览器中访问本机的局域网 IP 进行压制提交。

【系统托盘右键功能】
  在右下角 SlimBox 图标上点击鼠标右键：
  • [🌐 打开 Web 页面]     : 在浏览器中打开 SlimBox 控制台 (或直接双击托盘图标)
  • [📁 打开输出目录]     : 在资源管理器中直达压制输出文件目录 (outputs)
  • [⚙️ 设置存储目录...]   : 调出原生文件夹选择器，选择大容量外置盘 (D/E盘) 作为存储目录，自动保存至 config.json
  • [☑/☐ 开机自动启动托盘] : 普通用户级自启动设置 (无需管理员授权，随开机进桌面自动常驻托盘)
  • [⚙️ 安装系统服务]     : 调起 Windows 原生 UAC 授权提示，一键安装为 7x24 小时开机自启后台服务并配置防火墙
  • [🛑 卸载系统服务]     : 调起 Windows 原生 UAC 授权提示，一键停止并彻底删除系统服务与防火墙规则
  • [❌ 退出 SlimBox]     : 安全停止后台队列并退出

【原生贴心特性】
  1. 单实例防护：重复双击 slimbox.exe 不会冲突报错，自动帮您唤醒已打开的 Web 页面。
  2. 端口自动顺延：若 8080 端口被迅雷或其他软件占用，自动寻找 8081/8082 等空闲端口并自动打开对应网页。
  3. 挂机防休眠：当队列中有压制任务时，自动阻止 Windows 系统进入休眠/睡眠状态；压制完成后恢复正常节能。
  4. 绿色纯净：零 .bat 批处理文件，避免杀毒误报与乱码，所有配置自动持久化于同级 config.json。

【硬件加速支持】
  SlimBox 启动时会自动探测本机显卡硬件加速能力：
  - NVIDIA GeForce/RTX 系列 : 自动开启 hevc_nvenc / h264_nvenc 硬件编解码
  - Intel Core 核显/独显    : 自动开启 hevc_qsv / h264_qsv (QuickSync) 硬件编解码
  - AMD Radeon 系列         : 自动开启 hevc_amf / h264_amf 硬件编解码
  - 通用 CPU 降级兼容       : 自动使用 libx265 / libx264 多线程高效压缩

【目录文件说明】
  - slimbox.exe          : 主程序 (双击运行，托盘常驻，集成服务管理)
  - slimbox-cli.exe      : 命令行客户端 (供批量压制脚本或终端自动化调用)
  - bin/                 : 内置便携式硬件加速 ffmpeg.exe (已内置综合探针，无需额外依赖)
  - web/                 : 前端界面资源文件 (支持实时热重载定制)
  - config.json          : 用户自定义配置 (存储目录、端口，由软件自动生成)
  - data/                : 默认任务数据库、上传暂存区 (uploads) 与压缩产物区 (outputs)
