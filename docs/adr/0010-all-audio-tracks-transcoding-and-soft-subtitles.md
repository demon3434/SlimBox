# 0010 - 全音轨保留压缩与软字幕全拷贝封装策略

## 背景与决策

电影电视剧片源通常包含原声、配音等复数音轨，以及多语言软字幕。过度粗暴地仅保留单音轨或直接丢弃字幕会严重损害观影体验。

我们决定在各预设档位（360p 至 4K）中，默认对输入源视频的所有音频流进行全量映射与保留，并统一压缩为低码率 AAC 格式；同时，所有内嵌字幕流默认采用软字幕直通模式（`-c:s copy`）完整封装至输出容器中。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **音轨完整性优先**：用户针对音轨处理方式明确选定选项 B（“保留所有音轨并统一转为 AAC，兼顾完整性”），不为了片面压榨几十兆体积而牺牲原片的多语言与导评音轨。
> 2. **软字幕直通非烧录**：用户选定字幕策略选项 A（“全部封装软字幕 copy”），排除硬字幕烧录对画面造成的二次画质折损及无法关闭字幕的问题，同时零 CPU 额外消耗。
