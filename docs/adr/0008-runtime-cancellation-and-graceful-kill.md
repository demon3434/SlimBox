# 0008 - 运行中转码任务的即时可中止机制与安全退出

## 背景与决策

视频转码（尤其是低功耗平台上的 H.265 转码）属于重负载长时间运行任务。用户可能因为误提交错误参数、急需释放 CPU 资源或不需要该文件而需要强行干预。

我们决定在转码后端建立基于 Go `context.Context` 与进程组信号传递的即时中止通道，允许用户在 Web UI 或 CLI 任意时刻点击或发送“终止任务”指令。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **强行终止诉求确立**：用户明确提出“我还希望用户可以随时终止正在运行的压缩任务”。
> 2. **资源与残片清理边界**：收到终止指令后，后端向底层的 FFmpeg 子进程及其进程组发送 `SIGTERM`（超时后强制 `SIGKILL`），立刻释放 CPU 与内存占用；同时自动清除当前生成的半截损坏临时输出文件，将任务标记为 `aborted`，并将队列推进至等待中的下一个任务。
