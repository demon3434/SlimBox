# 0009 - 嵌入式 SQLite 持久化与可选凭证鉴权体系

## 背景与决策

为保证 SlimBox 在 Docker 重启、N1 掉电或升级时不丢失任务进度、自定义参数与历史记录，需要轻量级的状态持久化机制。同时，内网与可能的外网访问场景对安全性有不同诉求。

我们决定在外挂 USB 数据卷根目录下采用单文件 SQLite 数据库持久化全部元数据，并设计“默认免密、环境变量可开”的可选鉴权中间件。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **认证模式选定**：用户确认选择选项 B（“可选 API Token / 访问密码”）。在纯受信任内网环境下保持免密即用；当用户配置了环境变量（如 `SLIMBOX_PASSWORD` 或 `SLIMBOX_API_KEY`）时，Web 界面提示输入密码解锁，CLI 客户端通过 `--token` 或 Header 附带认证凭据。
> 2. **零运维单文件存储**：SQLite 无需独立数据库守护进程，所有任务排队记录、用户自定预设表均存储在 `/data/slimbox.db` 中，即使容器销毁重建，外接盘挂载后数据即刻完整复原。
