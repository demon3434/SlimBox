# 0004 - 声明式存储生命周期与可配置清理策略

## 背景与决策

ARM 宿主机挂载的 USB 外置存储设备虽然容量高于内置 eMMC，但面对连续大体积高清电影批处理任务时，源文件与转码成品的双重留存仍可能引发磁盘溢出。

我们决定在系统设置中引入细粒度、声明式的存储生命周期管理策略，而不是采用单一的死板删除逻辑。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **策略可配置化**：用户针对生命周期方案选择选项 C（“策略可配置”），系统必须提供显式配置项开关：
>    - `delete_source_after_transcode`：单次转码成功后，是否立即自动删除暂存的源视频文件；
>    - `delete_output_after_download`：转码成品被 Web 浏览器或 CLI 客户端完全下载完成后，是否立即自动清理；
>    - `retention_hours`：未被下载或保留成品的超时自动淘汰时长。
> 2. **赋予操作者完整控制权**：避免系统私自删除用户可能尚未备份的源文件，也允许全自动批量流水线实现“零残留暂存盘”跑批。
