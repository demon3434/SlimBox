# 0003 - 压缩参数分层模型与中立自主选择机制

## 背景与决策

视频压缩需求在不同使用者和不同设备算力之间差异显著。过度简单的预设无法满足进阶调参需求，而复杂的 FFmpeg 原生命令行对初级用户门槛极高。

我们决定将压缩参数分为两层：面向初级用户的“全分辨率预设矩阵”（覆盖 360p、480p、720p、1080p、2K/1440p、4K 的常用电影压缩参数），以及面向高级用户的“自由配置高级参数画布”。同时确立**中立选择原则**：系统绝不越俎代庖替用户默认勾选某个档位，必须由用户自主选择。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **双层用户分流明确**：“我希望对高级用户，可以给更多的参数，自由配置；小白用户，就预设几个档位，每种分辨率都设置一个常用的电影压制的参数集合，从360p到4k。”
> 2. **禁止强加默认推荐**：“不要帮用户选择档位，让用户自己选择。”系统界面与 API 默认不提供强制默认预选（Default Selected），强制用户进行显式确认，防止因系统默认选中 x265 或高分辨率导致 N1 等低算力设备因误点而陷入极其漫长的无效转码。
