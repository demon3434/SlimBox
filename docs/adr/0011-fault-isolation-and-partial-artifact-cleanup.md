# 0011 - 故障隔离调度与半成品碎片垃圾回收策略

## 背景与决策

在连续跑批处理数十个视频文件的流水线中，个别损坏原片可能引发转码异常。若因单个任务异常导致整个队列阻塞挂起，将直接破坏通宵批量转码的可用性；而异常中断留下的半截损坏视频文件若不予处理，会迅速蚕食外接 USB 存储空间。

我们决定采取故障隔离调度机制：单个视频任务发生转码报错时，记录完整 stderr 日志并标记为失败，队列立即推进至下一个任务；同时，针对失败任务执行即时残片清理，物理删除已生成的半成品文件。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **非阻塞连续跑批**：用户赞同“记录错误并自动跳过，继续下一个”的非阻塞故障隔离策略，避免通宵批量压制被个别异常源文件卡死。
> 2. **明确的残片清理约束**：用户针对失败场景提出强制要求——“但是失败后，要清理失败的半成品文件，节约磁盘”。因此系统在捕获到 FFmpeg 非零退出码、异常崩溃或中断后，必须同步触发残片清理钩子，彻底 unlink/remove 当前未写完的损坏文件，保证 USB 磁盘空间零无效残留。
