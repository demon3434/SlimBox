# 0005 - CLI 批量处理闭环与状态断点恢复机制

## 背景与决策

非图形化使用场景下，用户经常需要对一个目录或视频列表（如多集电视剧、多部电影）进行脱机无人值守批量压制，中途若遭遇断网、客户端退出或宿主机异常，需能够平滑恢复。

我们决定设计独立的 CLI 客户端工具，通过调用 N1 Docker 后端 REST API，构建“扫描 -> 逐个上传 -> 轮询压制 -> 自动下载回本地 -> 记录状态”的闭环，并以本地状态清单文件（State Manifest）保障断点跳过与续批。

### 用户补充细节

> **用户针对该项提出的补充与扩展：**
> 1. **全链路批处理认可**：用户确认该批处理闭环方案“完全符合预期”，明确批处理的核心形态为按列表或本地目录中的视频清单，逐个向 N1 传输、监控与取回。
> 2. **断点跳过与故障隔离**：通过在本地维护任务完成状态记录（如 `.slimbox-state.json`），已成功下载处理完毕的文件在后续重复运行同一批次任务时自动识别并跳过，实现稳健的无人值守断点续跑。
